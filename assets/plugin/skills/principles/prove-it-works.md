# Prove it works

Check the real thing: run the feature, read the stored value, drive the command, inspect the
diff. Proxies (it compiles, a self-report, cached output, a file's mtime) don't count. When a
check fails, suspect the way you observed before the system. Script the check when you can, so
it can be rerun, and keep its output where the user can see it. "Inconclusive" or a check on
the wrong surface is not a pass.
